# 2D Side-Scroller Game

A simple 2D side-scroller game built with [Godot Engine](https://godotengine.org/). Players move through levels, avoid obstacles, and defeat enemies.

## Features
- Player movement: left, right, and jump
- Enemies with simple AI and movement patterns
- Collectible items for score or power-ups
- Basic level design with platforms and obstacles
- Animated characters and enemies

## Controls
- `Arrow Left` / `Arrow Right` – Move
- `Space` – Jump
